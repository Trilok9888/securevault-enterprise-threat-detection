# Windows Security Endpoint

## Overview

SEC-WIN11-01 is the primary Windows endpoint in the SECURE VAULT lab.

It is used to generate endpoint telemetry, test security monitoring, validate network communication, and later forward logs to the SIEM.

## Virtual Machine Configuration

```text
VM Name:        SEC-WIN11-01
Operating OS:   Windows 11
Memory:         4 GB
CPU:            3 vCPU
Disk:           80 GB
Hypervisor:     Oracle VirtualBox
```

VirtualBox Guest Additions were installed to improve display handling, mouse integration, and overall VM usability.

## Network Configuration

The Windows endpoint uses a static IP address on the SEC-LAB network.

```text
IP Address:      10.10.10.10
Subnet Mask:     255.255.255.0
Default Gateway: None
```

The endpoint communicates with the host through the isolated Host-Only network.

A second NAT adapter is used temporarily when Internet access is required for software downloads and updates.

## Connectivity Validation

Host-to-endpoint connectivity was verified using:

```powershell
ping 10.10.10.10
```

Successful communication was confirmed with:

```text
Packets Sent: 4
Packets Received: 4
Packet Loss: 0%
```

## Firewall Configuration

Windows Defender Firewall remains enabled.

A dedicated inbound ICMP rule was created to allow controlled ping testing from the host:

```powershell
New-NetFirewallRule -DisplayName "SEC-LAB Ping" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -Action Allow -RemoteAddress 10.10.10.1 -Profile Any
```

This approach maintains endpoint firewall protection instead of disabling the firewall.


These snapshots provide rollback points for future testing and security experiments.

## Sysmon Installation

Microsoft Sysmon was installed to provide enhanced endpoint telemetry.

Installation directory:

```text
C:\Tools\Sysmon
```

Primary files:

```text
Sysmon64.exe
sysmonconfig.xml
```

Sysmon was installed using:

```powershell
.\Sysmon64.exe -accepteula -i .\sysmonconfig.xml
```

## Sysmon Service Verification

The Sysmon service was validated using:

```powershell
Get-Service Sysmon64
```

Expected result:

```text
Status: Running
```

Test activity was generated by launching applications such as Notepad.

Sysmon events were validated using:

```powershell
Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" -MaxEvents 10
```
